# Материалы реализации плана

Итоговое решение и ограничения: [отчет](../../reports/performance-implementation-2026-09-22.md).

## Конечная версия

- `final-abba.*` - основное сравнение baseline рабочего дерева с конечным кодом, 6 прогонов на вариант; normal GOMAXPROCS, NoAuth в лаборатории, настоящий SDK/scrape.
- `final-abba-environment.json` - CPU, настройки и SHA-256 измеренных бинарей. Версия схемы metadata этой серии предшествует полю completed; все 12 логов завершились PASS. Linux SC_CLK_TCK=100.
- `functional-checks.txt`, `final-checks.txt`, `profiling-checks.txt`, `crossbuild.json` - functional/race/lint/сборки. Opt-in performance-тесты запускаются отдельно от обычного набора.
- `ws-idle-*.txt`, `ws-buffer-*.txt` - самостоятельная цена WS write buffer. Idle-тест учитывает оба WS конца, без TLS и obfs.
- `tls-handshake-bench.txt` - полный и resumed TLS, с проверкой DidResume.
- `routes-*.txt` - алгоритмическая стоимость поиска доменного правила.
- `dns-local.txt` - системный LookupIP для localhost; не является замером публичного DNS.
- `pgo-*` - отдельные профили каждого процесса, независимая приемка, размеры и время сборки. Лабораторный PGO в выпуск не принят.
- `arm-small-*` - 6 прогонов на вариант и 10200 малых наблюдений на сценарий, настоящий ARMv8, direct/obfs, GOMAXPROCS прокси=1 и генератора=3. Все ответы прошли проверку, временный стенд удален.
- `arm-generator-*` - повтор ARM obfs small/bulk/upload/mixed с генератором на трех Go P, по 2 прогона. `arm-abba.*` - начальный короткий ARM-тест, где генератор также ограничен одним P; его mixed-регрессия не считается успешной приемкой.
- `netem-*`, `member-rtt.json`, `udp-results.txt` - изолированные сетевые сценарии, повтор спорного выброса, экономия greeting RTT и UDP-over-TCP. Эти результаты не заменяют рабочий WAN.
- `ws-create-*`, `ws-pool-*` - цена создания WS и отвергнутый прототип ограниченного pool. Pool отсутствует в конечном коде.

В JSON latency p50/p95/p99 рассчитываются по объединенным запросам. Bootstrap CI относится к медиане p99 независимых прогонов. Для bulk малый размер выборки недостаточен для надежного p99. CPU /proc имеет дискретность 10 мс, для малых кратких сценариев его нельзя трактовать как точную стоимость одного запроса. RSS зависит от GC и предыдущих сценариев процесса.

## Промежуточные эксперименты

`baseline-abba.txt`, `perf01-*`, `combined-stage2.txt` и `perf02-*` измеряют последовательное добавление coalescing и WS buffer до окончательной проверки mixed. `process-abba.*` и `mixed-abba.*` относятся к варианту **без финальных scheduling points**. Его регрессия mixed latency была обнаружена и исправлена. Эти данные сохранены как история проверки гипотезы, **не как приемка конечного кода**. Проценты из разных стадий нельзя складывать.

`git-status-before.txt` и `baseline-hashes.json` фиксируют исходные незакоммиченные изменения. `baseline-build-source.patch` восстанавливает Go-код измеренных baseline-бинарей поверх `c0f137a9f79b748dd5bb8f24a0c1d7559cb4d890`, включая диагностический пакет. Применение проверено на чистом архиве HEAD. Это патч для сборки в отдельном checkout, не замена исходным тестам или текущим исправлениям. Для измерений используйте текущий `probe-final` отдельно; новые performance-тесты в baseline-патч не включены.

`final-source-hashes.json` фиксирует конечные Go-файлы, скрипты, зависимости, README и пример конфигурации. `changed-baseline-files.json` перечисляет 12 файлов исходного снимка, измененных этой задачей. Все остальные файлы исходного снимка сохранены побайтно, удалений нет. Новые файлы реализации и проверки дополняют снимок; исходные H01-H05/R01 не отменялись.

Полные request/resource JSONL, временные тестовые сертификаты, бинарники, runtime traces и CPU profiles остаются в `/tmp/s5core-implementation-20260921/`; в репозитории сохранены только текстовые свидетельства. Временный каталог не является долговременным архивом.

Повторение: [руководство стенда](../../performance-validation.md). ARM loopback проверен в описанных сценариях; рабочий DNS/WAN, полный пик нагрузки и canary требуют отдельной приемки.
