# Доработки по аудиту 05.10.2026

Источники: [аудит](../reports/code-audit-2026-10-05.md) и дополнительный
список восьми замечаний. Пересечения объединены; дополнительные дефекты
копирования дат, повторного reload и начальной блокировки UDP сохранены.

Статус "исправлено локально" требует воспроизведения до исправления и
проверки после него. "Принято" требует также полного набора проверок и
соответствующей проверки работающих бинарей. Отсутствие предупреждений не
доказывает доставку голоса. Изменения формата протокола требуют описания
совместимости и перехода обеих сторон.

Текущий этап: полный локальный gate пройден (1010 тестов, 0 отказов).
Все три сервера и три клиента роутера обновлены до RC3; начальные проверки
и хеши пройдены. [Установка C/A](../reports/rc3-fleet-rollout-2026-10-05.md). Внешние проверки GitHub/Windows и длительная приемка
Discord остаются открытыми, поэтому общая приемка не объявлена. См. [результаты](../reports/code-audit-fixes-2026-10-05.md). Проверки до правок описаны в исходном аудите;
локальные результаты после правок сохраняются отдельно. Остаточные ограничения
истории после рестарта описаны в [предложении формата](../design/server-key-contribution.md).
Локальные измерения упаковки: [отчет A-10](../reports/bulk-framing-audit-2026-10-05.md).

После установки найдены еще два P2 и один P3: замена владельца имени,
сохранение runtime-ограничений при повторном Start и гонка чтения Boot.
[Дополнительный проверочный список](../reports/code-audit-followup-2026-10-05.md)
закрыт локально, полный gate дал 1022 теста без отказов. Эти изменения
на работающие узлы пока не установлены.

## Основные пункты

| Пункт | Статус | Критерий проверки |
|---|---|---|
| A-1: replay | локальная проверка пройдена; предложение нового формата отдельно | Мусор не меняет историю; одновременный replay принят ровно один раз; действующие записи не вытесняются емкостью; удержание покрывает окно эпох; отказ не отличается от неверного AEAD по ответу и бюджету. Отдельное описание вклада сервера в ключи и перехода формата |
| A-2: приватность ветки | пять неопубликованных коммитов обезличены; опубликованная история сохранена | Относительные ссылки; приватный снимок исключен; проверено содержимое всех неопубликованных коммитов до отправки; опубликованная история сохранена |
| A-3: писатели файла | локальные проверки reload/внешних правок пройдены | Автосохранение не затирает внешние правки; reload сохраняет несохраненные изменения SDK и счетчики; конфликт сообщается явно |
| A-4: перегрузка KDF | локальная проверка перегрузки пройдена | Нехватка бюджета не увеличивает счетчик неверных паролей; правильный вход работает после освобождения бюджета |
| A-5: half-close | локальные проверки тишины после FIN и активного ответа пройдены | Молчащее назначение закрывается по бюджету; нормальный ответ после FIN сохраняется; слот освобождается |
| A-6: назначения UDP | три пути и запрет broadcast на сокете проверены локально | Broadcast и специальные сети отвергнуты на всех трех путях; сокет не разрешает broadcast; ошибка перечисления интерфейсов не открывает доступ |
| A-7: уникальность аккаунтов | отказ startup/reload при дубликатах проверен локально | Дубликаты ключей, имен и ID отвергнуты при старте, reload и добавлении, включая выключенный аккаунт |
| A-8: отзыв TCP | локально проверены отзыв, квота, срок и grace | Выключение, удаление, истечение и квота завершают медленный поток в ограниченное время без ожидания 32 КиБ |
| A-9: память DNS | локальная проверка памяти и отмены пройдена | Ожидающая короткая датаграмма держит память пропорционально размеру; лимит очереди и освобождение при отмене проверены |
| A-10: bulk padding | измерено локально; см. отчет bulk framing | Проверены длины кадров и цена hot path; сопоставимые замеры до/после; нет заявления об ускорении без измерений |
| A-11: Resync | локальная проверка изоляции Resync пройдена | Дорогой HMAC не держит общий замок приема; чистая сессия обслуживается рядом с нагрузкой; очередь остается ограниченной |
| A-12: согласование MTU | локальная проверка потери всех limitACK пройдена | Потеря всех limitACK не оставляет разные пределы навсегда; обе стороны возвращаются к согласованному состоянию с ограниченным числом проб |
| A-13: счетчики проб | счетчики размерных проб и два отдельных эпизода проверены локально | EMSGSIZE размерной пробы отдельно от сетевых ошибок; WARN показывает прирост за эпизод; семантика полей документирована |
| A-14: ротация | локальная проверка отказа и восстановления ротации пройдена | Неудачный rename не теряет текущую и последующие записи; успешная ротация восстанавливается |
| A-15: метрики трафика | CONNECT, квоты, native/fallback и TCP-framing проверены локально | Один уровень учета native и fallback; каждый байт учитывается один раз; квоты и метрики различены |

| A-18: административный срок | локально проверены срок старого handle и независимость SDK-снимков | Каждая операция старого handle отказывает истекшему и еще не действующему аккаунту |
| A-19: аварийный конец TCP | RST назначения через настоящий obfs-сервер и клиентский релей проверен | RST/таймаут туннеля завершает обе стороны и освобождает слот; приложение получает аварийный конец; чистый half-close сохраняется |
| A-20: снятие рекомендации | локальная проверка снятия рекомендации при следующем туннеле пройдена | Уже работающий клиент перестает использовать снятую рекомендацию без перезапуска; формат совместим |
| A-21: MTU framing | локальная проверка граничного кадра пройдена | Верхняя граница проверена сервером, клиентом и библиотекой; граничный кадр читается; переполнение невозможно |

| A-23: UDP WARN | локальная проверка 300 отбросов/одного WARN пройдена | Битые UDP увеличивают счетчик, число строк ограничено на ассоциацию, валидный поток продолжается |
| A-24: гигиена и утилиты | утилиты и приватность проверены локально; Windows execution отдельно | Опубликованные пути исправлены новым коммитом; сжатые данные проверены и сведены к необходимым артефактам; PID и каталоги временных файлов безопасны; netwatch не изменяет общий каталог; публичные отчеты обезличены |
